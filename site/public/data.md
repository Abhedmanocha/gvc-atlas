# Data contract

Everything under `site/public/data/` is generated by `uv run --project pipeline python -m mrio`
(load → metrics → export, all years, ~10 s once cached). Code: `pipeline/mrio/metrics.py`.

## Conventions

- Economies `e` = 0..72 in `meta.json` order (72 = RoW). Sectors `s` = 0..34 (`c1`..`c35`). Node `n = e*35 + s`.
- Rows: every economy has 37 rows, `r` = 0..34 the sectors `c1`..`c35`, **35 = `all`** (whole economy), **36 = `mfg`** (c3..c16).
- Arrays follow `meta.json` order (economies, sectors, years). No labels inside data files.
- Units: US$ million (current) for levels; everything else is per $1 of the row's gross output, or a ratio, as stated.
- Numbers have 4 significant digits. `null` = undefined (no output, no exports, no foreign value added).
- In the per-$ arrays `va`, `direct`, `home`, `third`, `inputs`, `imp`, values with |v| < 1e-5 are written as 0 (scalars are computed before this cut; identities hold to ~1.5e-4 in the files).
- Rows with zero output (about 50 nodes a year, mostly c35) have zeros in arrays and `null` in ratios.

## Files

| file | content | shape of each field |
|---|---|---|
| `{year}/{ECON}.json` | all fields below for one economy-year | array field: `[37 rows][73 or 35]`; scalar: `[37 rows]` |
| `{year}/index.json` | scalar fields for every economy | `[73 economies][37 rows]` |
| `series/{ECON}.json` | scalar fields for every year | `[8 years][37 rows]` |

Detail files are 135–162 KB; index ~235 KB; series ~26 KB. Total 93 MB (30 MB gzipped).

## Definitions

Z intermediate flows (row sells to column), F final demand (`F1..F5` per economy), x gross output.
h = the row's own economy. `E_j` = gross exports of node j (intermediate + final sold to other economies).

- A = Z x̂⁻¹ (column j = 0 if x_j = 0). v = 1 − 1ᵀA, value added per $ of output **including net taxes on products** (r64 + r99 + r61..trs; ADB's convention, needed to reproduce its GVC indicators; product taxes are attributed to the economy of the paying industry).
- B = (I − A)⁻¹ global Leontief inverse. A_d = A restricted to domestic (same-economy) blocks, A_f = A − A_d, L = (I − A_d)⁻¹ local inverse.
- G[c, j] = Σ_{i∈c} v_i B_ij: value added of economy c embodied in $1 of j's output. Σ_c G[c, j] = 1.

**Row aggregation.** A row's value is a ratio of flows summed over its nodes. Per-$-of-output fields:
f_R = Σ_{j∈R} f_j x_j / Σ_{j∈R} x_j. Export ratios (`gvc_b`, `gvc_f`): weights E_j. Levels (`x`, `e`, `dest`): sums.
`hhi`, `top`, `topva`, `nsup`, `fva`, `impsh` are computed from the row's aggregated arrays, not averaged.

### Array fields (detail files only)

| field | length | definition | unit |
|---|---|---|---|
| `va` | 73 | G[c, R]: value added from economy c embodied in the row's output. Also the disruption exposure to c. | per $ |
| `direct` | 73 | Σ_{i∈c} G[c,i] A_ij: c's value added arriving in inputs bought straight from c. 0 at c = h. | per $ |
| `home` | 73 | Σ_{i∈h} G[c,i] A_ij: c's value added arriving in inputs bought from the home economy. | per $ |
| `third` | 73 | Σ_{i∉c,h} G[c,i] A_ij: c's value added arriving through inputs from any other economy (for c = h: home value added returning in imports). | per $ |
| `inputs` | 73 | Σ_{i∈s} Z_ij / x_j: intermediate inputs bought from economy s (s = h: domestic). | per $ |
| `dest` | 73 | Σ_{k∈d} Z_jk + Σ F_j,d: gross exports to economy d (0 at d = h). | US$ m |
| `imp` | 35 | Σ_{i∈p, i∉h} Z_ij / x_j: imported intermediate inputs of product p. | per $ |
| `impsh` | 35 | Σ_{i∈p, i∉h} Z_ij / Σ_{i∈p} Z_ij: import share of the row's intermediate use of product p. | 0–1 |

Identity: `direct[c] + home[c] + third[c] + own·[c = h] = va[c]`.

### Scalar fields (detail, index, series)

| field | definition | unit |
|---|---|---|
| `x` | gross output | US$ m |
| `e` | gross exports, Σ `dest` | US$ m |
| `own` | v: the row's own value added (incl. product taxes) per $ of output | per $ |
| `fva` | Σ_{c≠h} `va[c]` = 1 − `va[h]`: foreign value added in output | per $ |
| `fdirect` | Σ_{c≠h} `direct[c]`: foreign value added bought directly from its origin. Hidden foreign = `fva − fdirect`. | per $ |
| `hhi` | Σ_{c≠h} (`va[c]` / `fva`)²: concentration of foreign origins (RoW counts as one origin) | 0–1 |
| `top` | economy index of the largest `va[c]`, c ≠ h, c ≠ RoW | index |
| `topva` | `va[top]` | per $ |
| `nsup` | number of foreign economies (incl. RoW) with `va[c]` ≥ 0.01 | count |
| `imports` | Σ `imp`: imported intermediate inputs | per $ |
| `gvc_b` | backward GVC participation, 1 − Σ m_j E_j / Σ E_j with m = vL (Borin & Mancini 2019, source-based, by exporting sector) | share of exports |
| `gvc_f` | forward GVC participation, Σ m_j (E_j − Y^x_j − T_j) / Σ E_j; Y^x = final exports, T = A_f L y^d (intermediate exports absorbed by the direct importer's domestic final demand y^d) | share of exports |
| `up` | output upstreamness (Antràs et al. 2012): U = (I − Δ)⁻¹1, Δ_ij = Z_ij / x_i; output-weighted over the row. 1 = all output goes to final use. | steps |
| `rca` | (VAX_R / VAX_h,all) / (Σ_e VAX_e,R / Σ_e VAX_e,all), VAX_i = v_i Σ_k B_ik Σ_{d≠h(i)} y_kd: revealed comparative advantage in value added absorbed abroad. 1 for `all`. | ratio |

Derived, not stored: domestic value added in output `1 − fva` (global inverse, includes value added
that left and came back); domestic value added share of exports `1 − gvc_b` (local inverse, B&M);
total GVC participation `gvc_b + gvc_f`.

## Validation (`pipeline/tests/test_metrics.py`)

- Identities: Σ_c G = 1; with r64-only value added, Σ_c G + tax content = 1; route split adds up; G·y = value added by economy; aggregates equal sums of their sectors; Σ `e` = world cross-border flows; `rca[all]` = 1.
- Reference: 2024 IND c9 with r64-only value added: G from IND 0.642, PRC 0.041, USA 0.032; PRC 3.4 % of intermediate inputs.
- ADB `GVC Participation (BM, by exporting sector)` 2022–24, economies 1–72, all aggregation levels (0 = economy, 5 and 15 = ADB sector groups, 35 = sectors), rows with exports > US$1 m: `gvc_b` within 2e-4 (2024 to machine precision); `gvc_f` median error ≤ 1e-4, p99 ≤ 2e-3, economy level ≤ 2e-3, and < 1e-3 on rows sending < 1 % of exports to RoW (1.5e-3 in 2022).

**Known deviation.** ADB computed its workbook from a 75-economy table that splits Tajikistan and Uzbekistan out of RoW, which changes how partners absorb imports. Our `gvc_f` therefore differs from ADB's for exporters with large sales to RoW: KAZ, KGZ, RUS, MON, and a few rows each in GEO, LVA, PAK, KUW, SAU, UAE, ECU, KOR. The largest sector-row error is 0.068 (2023), and the largest economy-level error is 1.4e-3. 2022 also reflects a minor table revision (TAP rows up to 1.1e-3; CYP c25, which has negative value added, up to 0.05). `gvc_b` is unaffected.
